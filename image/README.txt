image 文件夹 —— 背景图片存放目录
=====================================

1. 把想用作背景的图片（png / jpg / jpeg / gif / webp / bmp / avif / svg）放进本文件夹。

2. 回到日历页面，打开右上角「设置」→「背景图片」，用下面任意一种方式让图片出现：
   · 点「扫描 image 文件夹」→ 在弹出的窗口中选择本文件夹（最省事，推荐）；
   · 点「刷新图片列表」→ 页面会自动尝试读取本文件夹（用本地服务器打开时通常可行）；
   · 手动把文件名填进同目录下的 manifest.js 里的数组，再点「刷新图片列表」。

3. 图片列表里点一下即可把它设为背景；「整页展开」和「长页面展开」可以各选一张，
   透明度（0~100%）与模糊度（0~100px）分别独立调节；
   点「同步为「…」的数值」可以把另一种展开模式的透明度与模糊度套用到当前模式。

4. 也可以不放进本文件夹，直接点「导入图片」从本地选择文件 ——
   这类图片会保存在浏览器本地存储中（会自动压缩），同样可以在列表里选择和使用。

5. 想把某张图片从背景列表里去掉：点该图片右上角的 ✕ 即可（无论它来自本文件夹还是导入的）。
   注意：从列表移除不会删除本文件夹里的文件；被移除的图片名会被记住，刷新时不会自动加回来。
   想重新使用它，点「扫描 image 文件夹」再选一次即可。

6. 如果图片上显示「文件不存在」，说明它已经被移走、改名或删除，
   点 ✕ 或者点「移除失效图片」把它从列表里清掉即可。
