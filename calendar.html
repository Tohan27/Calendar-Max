液态玻璃效果
开启后，日历、标记色、Shift 框选跨度、设置窗口等模块会变成半透明的「液态玻璃」质感（毛玻璃 + 高光边缘 + 柔和阴影）。此时「透明度 / 模糊度 / 模块不透明度」会锁定不变。
液态玻璃模式下，下方三个滑块已锁定（关闭液态玻璃后可继续调节）。默认白色背景下液态玻璃效果不明显，推荐与自定义图片背景配合使用。
背景图片
把图片放进项目目录下的 image 文件夹即可使用（可点「扫描 image 文件夹」或「刷新图片列表」识别），也可以直接点「导入图片」选择本地文件。整页展开与长页面展开共用同一张背景；「模块不透明度」控制日历、标记色、Shift 框选跨度等所有模块的遮挡程度，调低它背景就透出来更多。
每张图片右上角的 ✕ 可以把它从列表中移除（不会删除 image 文件夹里的文件）；如果图片显示「文件不存在」，说明文件已被移走或改名，点 ✕ 或「移除失效图片」即可清掉。

用户使用指南
一、基本导航
  • ‹ / ›：切换到上一个月 / 下一个月（带动画）。
  • 左侧月份胶囊：点击某个月份直接跳转；鼠标悬停其上滚动滚轮也能切换月份。
  • 左侧年份胶囊：悬停后滚动滚轮调整年份，再点「前往」跳转。
  • 「今」：回到今天所在的月份，并自动选中今天。
  • 右下角「跳转日期」：填写年 / 月 / 日，三项填齐后出现「前往」按钮，点击即可跳转（会自动校验该日期是否真实存在）。
  • 非本月的日期以浅灰显示，同样可以点击与标记。
二、标记色（右侧面板）
  • 单击：选中 / 取消选中该颜色。只有选中了颜色，「标记」按钮才会出现。
  • 双击：编辑该颜色（可改颜色与含义文字）。
  • 拖动：按住条目拖动可调整颜色顺序（松手前会用横线提示插入位置）。
  • ✕（悬停时出现）：删除该颜色，所有日期上使用它的标记会一并移除。
  • ＋（面板右下角）：新建标记色，可选预设色块或自定义取色，并填写含义（回车即可确认）。
三、标记日期
  • 单击日期：选中这一天。
  • Shift + 单击：追加选中，可多选。
  • 按住左键拖过多天：连续框选一段日期；Shift + 拖动为追加框选。
  • 展开某一周后，点击时间轴顶部的日期头同样可以选中 / 追加选中。
  • 点「标记」（或按 空格）：把当前选中的颜色标记到所有已选日期上。
  • 点「消除」（或按 Z）：清除已选日期的全部标记。
  • 日期下方的色条表示该日期已有的标记颜色（一行最多显示 3 个）。
  • 标题栏右侧的标记色块列出已选日期上已有的标记，点色块上的 ✕ 可把这些日期上的该标记一次性移除。
四、时间段标记（展开周时间轴）
  • 周行两端的 ▲ / ▼：把这一周展开成 24 小时时间轴（相邻周仍显示），再点一次收起。
  • 按 Tab：展开 / 收起「当前选中日期所在的一周」（没有选中日期时以今天为准），并自动跳到对应月份；这一周已经展开时，再按一次即收起。
  • 在时间轴上按住左键上下拖动：框选一段时间，蓝色高亮即为待标记区域。
  • Shift + 拖动：按设置里的「框选跨度」对齐（默认 30 分钟一档）。
  • 跟随鼠标的提示框会实时显示星期与具体时间。
  • 点「标记」（或 空格）：把框选的时间段标记为当前颜色。
  • 点「消除」（或 Z）：清除与该时间段重叠的所有时间段标记。
  • Esc：取消当前正在框选的时间段。
  • 今天所在的那一列会显示一条当前时间线；日期格左上角的橙色三角表示该日期有时间段标记。
时间段标记的编辑
  • 单击：选中该标记，上下会出现两个可拖动的手柄；此时点「消除」或按 Z 可以直接删除这个标记。
  • 长按约 1 秒（出现进度圆环）后拖动：移动该标记 —— 上下拖动改时间，左右拖动可换到别的日期；按住 Shift 移动会按跨度对齐。
  • Ctrl + 左键拖动：忽略鼠标下的时间段标记，直接压着它框选新的时间段——不会误选中、也不会误移动该标记。适合在已有标记的位置上补选或叠加标记（Mac 上可用 ⌘ 代替 Ctrl）。
  • 拖动上 / 下手柄：调整开始时间 / 结束时间；按住 Shift 同样按跨度对齐。
  • 右键：打开该时间段的「标记数值」面板。
五、标记数值（浮窗）
  • 打开方式：右键点击「已有标记的日期格」或展开周顶部的日期头，或右键点击时间段标记。
  • 同一天有多个标记时，面板顶部的小圆点可切换要编辑的标记，各自的数值分别保存。
  • 「＋ 添加数值」可选两种类型：
    · 百分制（进度条）：0~100 的滑块，也可以直接输入数字；
    · 二 ~ 七选项：一排按钮单选，标签组可在设置里自定义（如 优 / 良 / 差）。
  • 每个数值都能改名、都能用 ✕ 删除。
  • 拖动面板顶部的标题栏可以移动浮窗位置。
  • 「保存」写入数据；「取消」或直接点击面板外部则放弃本次修改。
六、日历管理（多日历）
  • 左上角的日历胶囊：点击展开列表，可直接切换日历，或选「管理日历…」打开设置。
  • 设置 → 日历管理：输入名称后点「新建日历」（名称留空会自动命名为 日历一、日历二……）；点击某一行即可切换；点 ✎ 重命名（回车确认、Esc 取消）；点 ✕ 删除。
  • 每个日历拥有各自独立的标记色、日期标记、时间段标记与数值，互不影响，适合用不同日历记录不同类别的事情。
  • 新建的日历是空白的，没有任何标记。
  • 为避免数据无处存放，至少会保留一个日历，删除前会二次确认（删除后无法恢复）。
七、设置项说明
  • 展开方式：「整页展开」的时间轴高度固定；「长页面展开」的时间轴更高，时间段更好点选。
  • Shift 框选跨度：预设的分钟档位，点击即选用，✕ 删除；也可在下方输入自定义分钟数后点「添加」。展开周后，右侧的跨度面板与设置里的是同一份数据。
  • 按钮选项预设（内容）：为 2~7 选项添加标签组（用 / 分隔，数量必须与选项数一致，例如 优/良/差）；这些标签组会出现在「标记数值」面板的下拉列表中。
  • 日历管理：新建、切换、重命名、删除日历。
  • 液态玻璃效果（设置 → 外观）：开启后日历、标记色、Shift 框选跨度、设置窗口等模块会变成半透明的毛玻璃质感（带高光边缘与柔和阴影）；此时背景的「透明度 / 模糊度 / 模块不透明度」三个滑块会锁定并变灰，关闭开关后即可继续调节。开关状态会被记住。
  • 背景图片：图片放进项目下的 image 文件夹即可选用（点「扫描 image 文件夹」可直接选择该文件夹，点「刷新图片列表」重新检测）；也可以点「导入图片」直接选择本地文件（导入的图片保存在浏览器本地）。整页展开与长页面展开共用同一张背景：透明度（0~100%）与模糊度（0~100px）调整背景本身；模块不透明度（0~100%）统一控制日历、标记色、Shift 框选跨度等所有模块的遮挡程度 —— 数值越低，模块越透明、背景透出来越多（100% 时模块完全不透明）。选「无背景」即可恢复纯色背景。

九、数据保存
  • 所有日历与标记数据都保存在本浏览器本地（localStorage），不需要联网，也不会自动上传。
  • 清除浏览器缓存 / 站点数据会导致数据丢失，重要数据请自行留意备份。
  • 「设置 → 数据占用」可以查看当前占用大小（按「日历数据 / 导入的图片 / 其他设置」分类），并可一键「清空当前日历的标记」或「清空全部数据」（都会二次确认，不可恢复）。
  • 删除标记色、标记或整个日历后，占用会真正变小；占得最多的是用「导入图片」导入的背景图；放进 image 文件夹的图片只记录文件名，几乎不占浏览器空间。
